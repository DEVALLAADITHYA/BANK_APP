 🏦 Streamlit Bank Application

A simple Bank Management Web Application built using Python and Streamlit.
This application allows users to create a bank account and perform basic banking operations such as deposit, withdrawal, balance checking, and updating mobile numbers through a simple interactive web interface.

📌 Features

Create a new bank account

Deposit money into the account

Withdraw money from the account

Check current account balance

Update registered mobile number

Interactive dashboard-style UI using Streamlit

Sidebar navigation for easy access to banking operations

🛠️ Technologies Used

Python

Streamlit

Object-Oriented Programming (OOP)
